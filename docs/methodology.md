# 层级多标签分类与新主题拒识：方法说明

本系统在纯 Python 标准库内实现多语专利摘要的层级多标签分类、概率校准与可解释拒识，
不依赖在线接口或第三方包。所有资源（概念词表、依赖、模型参数、阈值）离线冻结，
旧版目录与模型可随时复算。

## 1. 数据口径与基本纪律

### 1.1 家族（family）是唯一计量与隔离单位
- 同一发明的多国公开共享 `family`，其全部语种文档在训练/开发/验证切分时整体移动，
  翻译文本不会横跨训练与验证（`split.assert_family_isolation` 护栏）。
- 指标按家族计数，多国公开不被当成多次创新。
- 文档有公开日与优先权日；前推切分按家族最早公开日排序。

### 1.2 未标注不是负类（PU 语义）
- 只有带人工标签的家族进入节点训练样本；未标注家族在 `_doc_records` 阶段即被排除，
  绝不隐式当作负例。
- “当时还没有这个类”不是“专家判定不相关”：节点可用性在版本目录内判断，
  目录升级后的回填标签（`confirmed_at` 在新版生效后、公开日更早）是合法数据。

### 1.3 多父 DAG 与祖先约束
- 目录是带多父节点的有向无环图（DAG），如 `edge_ai` 同时是 `iot_network` 与 `ai`
  的子节点，可沿两条路径到达祖先。
- 预测输出经 `Catalog.closure` 取祖先闭包；`Catalog.violations` 作为评估护栏，
  正常情况下约束违规数为 0。

## 2. 文本表示

`text.TfidfVectorizer` 提供三种可比较的表示（`VectorizerConfig.mode`）：

| 模式 | 内容 | 跨语一致性 | 细类区分 | 适用 |
|---|---|---|---|---|
| `words` | 拉丁词形 + CJK 单字/bigram + 概念特征 | 高 | 中 | 默认，跨语对齐稳定 |
| `chars` | 字符 3/4-gram + 概念特征 | 中 | 高（词形敏感） | 复合词/屈折语种 |
| `both` | 两者合并 | 中 | 高 | 特征更密、解释性下降 |

### 2.1 冻结多语概念词表
- `resources/concept_lexicon.json` 把同一 `concept_id` 在 zh/en/de/ja 四语下对齐，
  是跨语一致性的主要通道。
- 概念特征**无条件保留**（即使训练段文档频率为 0）：这是运行期识别“训练段从未出现
  的新概念”的前提，否则新技术词面根本进不了向量。
- `is_marker=true` 的概念（如中文“网络”/英文 network，同时出现在通信与神经网络语境）
  在证据中显式标注 `ambiguous=true`。**排序高分本身不是归类证据**，歧义词必须与
  非 marker 证据共同出现才可采信。
- 拉丁词按 token 边界匹配，避免德语 `Gen` 误命中 `Energie**sparGen**` 这类子串污染；
  CJK 允许子串匹配。

### 2.2 轻量词干化（可选，默认关闭）
`stem_latin=true` 对拉丁词剥离常见屈折后缀，缓解德语复合/屈折。实验显示它对德语
精度仅有边际改善且略降跨语 Jaccard，因此默认关闭，作为可复现实验项保留。

## 3. 层级学习

### 3.1 局部节点二项分类器
- 每个节点一个纯 Python 逻辑回归（`LogisticModel`），加权 SGD、L2 正则、
  固定种子 LCG 洗牌，跨机器逐位可复现。
- 类别不平衡用逆频率权重；正样本按**家族**计数设门槛（`min_train_pos`），
  同家族多语翻译不重复计数。
- 正样本不足或只有单一类别的节点跳过训练，不在稀有节点上制造伪精度。

### 3.2 概率校准
- 开发段做 L2 正则梯度下降 Platt scaling，输出校准概率而非裸分数；
  带 Platt 先验修正，单类开发集退化为带先验偏置的 sigmoid 而不伪造校准。
- 稀有节点（正类家族数 < `rare_train_pos`）在子树内池化开发分数。

### 3.3 阈值选择
- 阈值只在开发段、按精度底线 `precision_floor` 选择：满足底线的候选中取 F1 最高。
- 没有任何阈值能满足精度底线时，阈值设为开发段最高观测概率之上——该节点运行期
  一律以 `insufficient_evidence` 拒识。**宁可单节点拒识交给专家，也不制造低精度接受**；
  系统不追求“把全部拒绝做成高精度”。

## 4. 校准拒识（带原因）

拒识分全局与节点两级，每条都带可核对原因：

| 原因代码 | 触发条件 | 含义 |
|---|---|---|
| `short_abstract` | 摘要字符数 < `min_tokens` | 证据载体过短 |
| `uncovered_topic`（孤儿概念） | 命中词表认识但无任何节点正向承接的概念 | 目录无法容纳的新技术 |
| `uncovered_topic`（全局 OOD） | 与最宽松已知主题地板的最大相似度仍过低 | 不属于任何已训练主题 |
| `insufficient_evidence` | 最高校准概率仍低于该节点阈值 | 证据不足，不下结论 |
| `node_ood_warning` | 部分节点未通过节点级 OOD 但已有接受 | 软警告，不改变已接受状态 |

### 4.1 两级 OOD 设计
- **全局门**用所有节点中最宽松的质心地板：文档只要贴近任一已学主题即放行，
  只有与全部已知主题都偏离的文档（真正新技术）才在这层被拦截。
- **节点级门**逐节点判断质心相似度，跨主题文档对错误节点天然 OOD，只排除该节点、
  不影响正确节点接受。
- OOD 剖面按语种分别建立（`centroids_by_language`），避免高资源语种的密集 n-gram
  主导余弦距离、误杀小语种；未见或单样本语种回退全局剖面。

### 4.2 硬拒识与软警告
`Prediction.is_abstained` 仅在**没有任何接受节点且存在阻断性原因**时为真。
带 `node_ood_warning` 的接受仍是有效分类；孤儿概念与全局 OOD 触发硬拒识。

## 5. 验证与错误三分法

### 5.1 前推（rolling-origin）切分
- 词表只在训练段拟合；校准、阈值、拒识参数只在开发段选择；验证段在全部选择冻结后打开。
- 默认两折：v1 折（训练截至 2021-06、开发 2021Q3、测试 2021Q4–2022）、
  v2 折（训练截至 2022 年底、开发 2023H1、测试其后）。
- 模型只对其目录版本生效期内的家族负责（`scoped_out_of_version` 记录跨版本数量），
  跨版本评分走复算通道而非版本内指标。

### 5.2 分层指标
- 宏观类（`macro`）与叶子/稀有子类（`leaf`、`rare_metrics`）分开报告，
  避免大类指标掩盖细类失败。
- 语种指标按同族每个语种文档单独预测、对照同一份家族真值统计。
- 报告接受率与拒绝原因分布，以及 Brier 校准误差、同族跨语 Jaccard 一致率。

### 5.3 错误三分法（`evaluation._triage_family`）
| 类别 | 判定 | 处理含义 |
|---|---|---|
| `missing_annotation` | 人工漏标，系统接受集合覆盖真值 | 成功补捕获，交专家确认 |
| `noisy_label` | 人工标签与真值冲突，模型按真值归类 | 模型抵抗脏标签，记录核对 |
| `known_misclassification` | 目录可容纳但判错节点 | 模型能力问题，进迭代 |
| `new_topic_handled` / `new_topic_force_fit` | 目录外新技术被拒识 / 被硬归 | 前者正确，后者必须清零 |

## 6. 版本化、迁移与复算

### 6.1 标签迁移必须有依据
- 迁移规则（rename/split/merge/deprecate/add）在目录历史规格中登记 `basis`，
  无依据的规则在 `load_history` 阶段被拒绝。
- `CatalogHistory.migrate` 输出逐条迁移留痕；无规则可用的节点标记 `unmapped`，
  绝不静默丢弃。

### 6.2 模型包不可变
- 每个模型包含 `manifest.json`，登记 model.json 与训练家族清单的 SHA256、字节数；
  加载时校验，篡改即 `BundleError` 拒绝。
- 旧版模型包可持续加载复算，不依赖当时在线状态。

### 6.3 拆分类不是技术涌现
- `versioning.diff_catalogs` 区分节点增删、迁移操作与多父路径变化，并附解释声明。
- `replay_on_frozen_families` 在**同一组冻结家族**上用新旧两版模型评分，
  用 `change_code`（split_expanded/merge_collapsed/renamed/new_node_available/…）
  解释路径与数量变化来自目录口径而非技术本身。
- 技术涌现只能由 `new_topic` 拒识经专家复核确认，不能用节点数量变化代替。

## 7. 已知局限（如实记录）
- 德语复合词/屈折使词面匹配弱于中英日，字符 n-gram 与词干化只能部分缓解；
  这是轻量离线方法的固有取舍，报告中按语种单独暴露而非掩盖。
- 单节点逻辑回归不建模节点间高阶交互，层级一致性主要靠祖先闭包后处理保证。
- 概念词表为冻结资源，语言外的全新术语仍需走 OOD/孤儿概念通道交专家，而非自动归类。
